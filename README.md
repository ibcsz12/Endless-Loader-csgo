# ⚡ Endless Loader for CS:GO

A custom C# / WinForms software loader designed for Counter-Strike: Global Offensive. It features an integrated UI theme swapper, smooth animations, and configurations for software builds.

---

## 📌 Features

* **Multi-Software Support**:
  * **Primordial**: Custom crack build with personal source fixes and improvements.
  * **Neverlose**: Custom crack implementation.
* **Modern GUI**: Built using Guna UI2 components with dynamic dark/light accent theme switching depending on the selected build.
* **Visual Effects**: Custom opacity fade-in / fade-out window animations on open and exit.
* **Auto-Save Credentials**: Remembers user login data locally via `Properties.Settings`.
* **External Links Integration**: Direct discord integration & external process handlers.

---

## 🛠️ Built With

* **Language**: C#
* **Framework**: .NET Framework (Windows Forms)
* **UI Library**: Guna.UI2.WinForms
